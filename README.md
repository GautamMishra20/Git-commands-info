# Git & GitHub Commands and Concepts

A beginner-friendly guide covering the most important Git and GitHub concepts with practical examples and explanations.

This repository is designed for students, beginners, and developers who want to learn Git and GitHub from the ground up.

---

## Topics Covered

### 1. Basic Git Commands

Learn the fundamental commands used in everyday Git workflows:

- `git init`
- `git status`
- `git add`
- `git commit`
- `git log`
- `git diff`

File: `01-basic-commands.md`

---

### 2. .gitignore and .gitkeep

Understand how to:

- Ignore unnecessary files and folders
- Protect sensitive files from being tracked
- Keep empty directories in a repository

File: `02-gitignore-gitkeep.md`

---

### 3. Undoing Changes

Learn different ways to reverse changes safely:

- Unstage files
- Restore files
- Reset commits
- Revert commits
- Recover from mistakes

File: `03-undoing-changes.md`

---

### 4. Branching, Merging and Merge Conflicts

Explore Git's branching workflow:

#### Branching

- Create branches
- Switch branches
- Delete branches
- Feature-based development

#### Merging

- Fast-Forward Merge
- Three-Way Merge
- Squash Merge
- Octopus Merge

#### Merge Conflicts

- Why conflicts happen
- Understanding conflict markers
- Resolving conflicts
- Aborting merges

File: `04-branching.md`

---

### 5. GitHub Fundamentals

Learn the basics of GitHub and how it works with Git:

- Git vs GitHub
- Repositories
- Issues
- Pull Requests
- GitHub Actions
- GitHub Pages

File: `05-github.md`

---

### 6. Remote Branches

Understand how branches work on GitHub:

- Local vs Remote Branches
- Publishing branches
- Tracking branches
- Fetching remote branches
- Deleting remote branches

File: `06-remote-branch.md`

---

### 7. Forking and Pull Requests

Learn the standard open-source contribution workflow:

- Forking repositories
- Origin vs Upstream
- Creating feature branches
- Creating Pull Requests
- Code review process
- Synchronizing forks

File: `07-pull-forking.md`

## Prerequisites

Before starting, make sure you have:

- Git installed on your system
- A GitHub account
- Basic command-line knowledge

Verify Git installation:

```bash
git --version
```
